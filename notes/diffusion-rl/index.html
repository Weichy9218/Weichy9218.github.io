1. 先分清两条相反主线：Diffusion for RL 与 RL for Diffusion

同样把扩散模型与强化学习放进一个框架，研究目标可以是完全相反的两个方向：

主线 优化目标 核心建模思路 代表工作
Diffusion for RL 用扩散模型增强决策、控制与规划能力 把整条状态–动作轨迹或连续多步动作分布建模为扩散生成过程，配合回报引导、Inpainting 或 Q 梯度对齐选出高回报行为 Diffuser (ICML 22), Diffusion Policy (RSS 23), QSM (ICML 24), GenPO (NeurIPS 25)
RL for Diffusion 用 RL 微调文生图/视频等生成模型，对齐不可微外部奖励 把 $K$ 步去噪链本身视为有限步 MDP（去噪步即决策步），用策略梯度直接优化美学、压缩率或 VLM 对齐度等黑盒奖励 DDPO (ICLR 24), DPOK (NeurIPS 23)

为什么在决策任务中引入扩散模型？

传统 RL 是自回归（autoregressive）的：每一步看到状态 $s_t$，输出动作 $a_t$，进入下一状态。而轨迹级扩散（Trajectory Optimization）一次性在整段规划视界 $H$ 上联合生成状态–动作序列，带来四项结构性优势：

  • 多模态（多峰）策略表达：面对绕障左行/右行等等价解，单峰高斯策略容易把两条可行路径平均成一条撞墙动作；扩散模型可无损表达任意复杂多峰分布。
  • 时序平滑与长程非贪心：反向去噪同时精修整条轨迹，避免了逐步贪心误差累积与高频动作抖动。
  • 条件与约束即插即用：初始状态、终点目标、避障或复合多目标奖励可在测试时以引导梯度或 Inpainting 注入，无需重训动力学模型。
  • 离线分布先验 + 在线信号微调：先从离线轨迹学得动力学可行流形，再叠加回报梯度或在线策略更新。

2. 理论基础：为什么可以把控制与规划改写为条件轨迹采样？

将一段长度为 $H$ 的轨迹组织为二维矩阵 $\tau^0 \in \mathbb{R}^{(d_s + d_a) \times H}$：

$$\tau = \begin{bmatrix} s_0 & s_1 & \cdots & s_H \\ a_0 & a_1 & \cdots & a_H \end{bmatrix}$$

2.1 前向加噪与反向去噪

前向扩散过程是固定的马尔可夫链，按方差表 $\{\beta_i\}_{i=1}^K$ 逐步向真实轨迹 $\tau^0$ 注入高斯噪声（记 $\alpha_i = 1 - \beta_i,\; \bar{\alpha}_i = \prod_{j=1}^i \alpha_j$），支持任意步一步闭式采样：

$$q(\tau^i \mid \tau^{i-1}) = \mathcal{N}\!\left(\tau^i;\; \sqrt{1 - \beta_i}\,\tau^{i-1},\; \beta_i \mathbf{I}\right), \qquad q(\tau^i \mid \tau^0) = \mathcal{N}\!\left(\tau^i;\; \sqrt{\bar{\alpha}_i}\,\tau^0,\; (1 - \bar{\alpha}_i)\mathbf{I}\right)$$

反向去噪过程从标准高斯噪声 $\tau^K \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ 出发，由参数化高斯核逐步恢复干净轨迹：

$$p_\theta(\tau^{i-1} \mid \tau^i) = \mathcal{N}\!\left(\tau^{i-1};\; \mu_\theta(\tau^i, i),\; \Sigma^i\right)$$

在 Ho et al. (2020) 的简化目标下，模型等价于预测注入的噪声 $\epsilon_\theta(\tau^i, i)$（或等价地直接预测去噪均值 $\mu_\theta$）：

$$\mathcal{L}_{\text{simple}}(\theta) = \mathbb{E}_{i \sim \mathcal{U}(1, K),\; \tau^0 \sim q,\; \epsilon \sim \mathcal{N}(\mathbf{0}, \mathbf{I})}\!\left[\big\|\epsilon - \epsilon_\theta(\sqrt{\bar{\alpha}_i}\,\tau^0 + \sqrt{1 - \bar{\alpha}_i}\,\epsilon,\; i)\big\|^2\right]$$

概念辨析：Denoising（去噪） vs. Sampling（采样）

去噪指给定第 $i$ 步带噪样本 $\tau^i$，通过网络单步去除部分噪声得到 $\tau^{i-1}$；采样指从纯噪声 $\tau^K$ 出发，沿 $i = K \to 0$ 连续迭代去噪直至生成 $\tau^0$ 的完整过程。

2.2 将控制转化为条件推断（Control as Inference）

引入二值最优性变量 $\mathcal{O}_t \in \{0, 1\}$，令 $p(\mathcal{O}_t = 1 \mid s_t, a_t) = \exp(r(s_t, a_t))$，则高回报轨迹的后验分布满足：

$$\tilde{p}_\theta(\tau) \propto p_\theta(\tau)\, p(\mathcal{O}_{1:H} = 1 \mid \tau) = p_\theta(\tau)\,\exp\!\big(\mathcal{J}(\tau)\big), \qquad \mathcal{J}(\tau) = \sum_{t=0}^{H} r(s_t, a_t)$$

利用一阶泰勒展开近似（类似 Classifier-Guided Diffusion），反向去噪的每一步只需在无条件均值 $\mu_\theta(\tau^i, i)$ 上叠加引导函数梯度 $g = \nabla_\tau \mathcal{J}_\phi(\tau)\big|_{\tau = \mu}$：

$$\tilde{p}_\theta(\tau^{i-1} \mid \tau^i, \mathcal{O}_{1:H}) \approx \mathcal{N}\!\left(\tau^{i-1};\; \mu_\theta(\tau^i, i) + \alpha \Sigma^i \nabla_\tau \mathcal{J}_\phi(\mu),\; \Sigma^i\right)$$

其中 $\alpha$ 控制引导强度：既可以在测试时自由更换或线性叠加多个 $\mathcal{J}_k(\tau)$ 实现多目标组合，又不改动已经学好的动力学扩散先验 $p_\theta(\tau)$。

3. 精读 Diffuser（ICML 2022）：长程稀疏任务胜出，高频控制受限

3.1 动机：Model-Based RL 为什么容易遭遇「模型利用（Model Exploitation）」？

传统 Model-Based RL 先用监督学习拟合单步转移模型 $\hat{T}(s_{t+1} \mid s_t, a_t)$，再在模型上用强规划器（如 CEM / MPPI）搜索最大化回报的动作序列。但任何拟合模型与真实环境都存在误差，强优化器会系统性地专挑模型最不准、被高估的盲区走捷径，导致纸面回报极高、真实环境执行崩溃。

Diffuser（Janner et al., ICML 2022）的核心洞见是让动力学建模与轨迹规划合二为一（Sampling = Planning）：

  • 局部小感受野 1D 时序 U-Net：单步去噪只强约束相邻若干步的动力学可行性，因此与具体轨迹长度解耦；多步迭代去噪把局部一致性逐层传播，合成全局连贯长程计划；
  • Inpainting 强约束起终点：每完成一步去噪，直接把当前观测状态 $s_0$（及目标状态 $s_H$）覆写回轨迹两端，就像图像补全一样自动生成中间路径。
Algorithm 1: Guided Diffusion Planning (Janner et al., ICML 2022)
Require: Diffuser μ_θ, return guide J_φ, guidance scale α, covariances Σ^i
while episode not done:
    Observe current state s; initialize τ^K ~ N(0, I)
    for i = K, K-1, ..., 1:
        μ ← μ_θ(τ^i)                                  # 无条件反向去噪均值
        τ^{i-1} ~ N(μ + α * Σ^i * ∇J_φ(μ), Σ^i)       # 注入任务回报梯度引导
        τ^{i-1}[s_0] ← s                              # Inpainting 固定当前起点状态
    Execute first action τ^0[a_0] in environment

4. 四篇关键延伸：Diffusion Policy、DDPO、QSM 与 GenPO 各自解了什么瓶颈？

4.1 Diffusion Policy（Chi et al., RSS 2023，arXiv:2303.04137）

  • 核心设计：不再联合生成高维状态序列，而是以视觉/本体观测历史 $O_t$（长度 $T_o$）为条件，直接对未来动作块（Action Chunk，长度 $T_p$）做条件去噪生成，并按滚动时域控制（Receding-Horizon Control）只执行前 $T_a$ 步动作再重新观测规划；系统对比了 1D CNN（FiLM 条件注入）与 Time-series Diffusion Transformer 两种去噪主干，并引入 DDIM 加速到实时控制频率。
  • 实验结果：横跨 4 个机器人基准套件、12 项操作任务（含强多模态接触任务 Push-T 与 Robomimic），相比 LSTM-GMM、BET、IBC 等此前 SOTA 平均性能提升 46.9%；代码开源于 real-stanford/diffusion_policy。

4.2 DDPO（Black et al., ICLR 2024，arXiv:2305.13301）

  • 核心理论（RL for Diffusion）：把 $K$ 步去噪链精确写成有限步 MDP，状态为 $s_t = (c, K-t, x_{K-t})$，动作为 $a_t = x_{K-t-1}$，策略为 $\pi_\theta(a_t \mid s_t) = p_\theta(x_{K-t-1} \mid x_{K-t}, c)$，仅在最终图像 $x_0$ 生成时获得稀疏奖励 $r(x_0, c)$。从而直接对去噪分布求精确策略梯度（及 PPO 式重要性采样裁剪版本 $\text{DDPO}_{\text{IS}}$）：
$$\nabla_\theta \mathcal{J}_{\text{DDRL}}(\theta) = \mathbb{E}\!\left[\sum_{t=0}^{K-1} \nabla_\theta \log p_\theta(x_{t-1} \mid x_t, c)\; r(x_0, c)\right]$$
  • 实验结果：在 Stable Diffusion v1.4 上直接优化难以用提示词描述的不可微目标（JPEG 压缩体积、LAION 美学打分以及基于 LLaVA VLM 问答的复杂图文一致性），优化效率与稳定性均显著超过传统的奖励加权回归（RWR）；开源代码见 kvablack/ddpo-pytorch。

4.3 QSM：Q-Score Matching（Psenka et al., ICML 2024，arXiv:2312.11752）

  • 核心问题与理论：如果在 Actor-Critic 中直接通过整条多步去噪链反向传播 $Q(s, a)$ 的梯度，会产生高方差与显存爆炸。QSM 注意到最优玻尔兹曼策略 $\pi^*(a \mid s) \propto \exp(\alpha Q(s, a))$ 的得分函数满足 $\nabla_a \log \pi^*(a \mid s) = \alpha \nabla_a Q(s, a)$，因此直接让扩散模型的得分网络 $\psi_\theta(a, s)$ 去匹配动作价值梯度：
$$\mathcal{L}_{\text{QSM}}(\theta) = \mathbb{E}_{(s, a) \sim \mathcal{D}}\!\left[\big\|\psi_\theta(a, s) - \alpha \nabla_a Q_\phi(s, a)\big\|^2\right]$$
  • 实验结论：更新策略时只需对单步去噪网络求导，完全避开跨去噪链的 BPTT，同时保留了隐式多峰探索能力（开源代码见 score_matching_rl）。

4.4 GenPO（Ding et al., NeurIPS 2025，arXiv:2505.18763）

  • 核心问题与机制：扩散/流策略长期难以直接接入 on-policy PPO，主要障碍在于多步采样后的动作边际对数概率 $\log \pi_\theta(a \mid s)$ 难以精确计算且不可逆。GenPO 设计了一种双虚拟动作交替更新（doubled dummy action）机制，实现了精确的扩散逆变换（exact diffusion inversion），把扩散策略干净地嵌入标准 PPO 裁剪目标。
  • 实验结果：在 IsaacLab 8 项大规模 GPU 并行仿真基准（Ant、Humanoid、Anymal-D、Unitree H1/Go2、Shadow Hand 灵巧手、Quadcopter、Franka 机械臂）上取得了优于高斯策略及其他扩散 RL 基线的在线训练效果。

5. 方法对比与工程选型结论

  1. 长程稀疏奖励 / 测试时动态换目标 → 选 Diffuser 一类的轨迹级扩散规划，用 Inpainting 和引导梯度绕开 TD 信用分配瓶颈。
  2. 高维视觉输入 / 接触丰富的多模态示范模仿 → 选 Diffusion Policy（条件动作块 + 滚动时域控制），兼顾实时性与多峰表达。
  3. 需要从零在线交互并结合 Critic 探索 → 离线/Off-policy 优先看 QSM（省去跨步 BPTT），大规模并行 On-policy 优先看 GenPO。
  4. 面向图像/视频生成模型的黑盒偏好对齐 → 走 RL for Diffusion（DDPO），把去噪链本身当作多步 MDP 做策略梯度。
