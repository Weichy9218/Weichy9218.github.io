Diffusion × RL：从 Diffuser 到扩散策略与奖励引导

Chuyang Wei · Diffusion Models / Reinforcement Learning / Planning

这篇把之前零散记的两篇笔记（Diffusion_RL_Explore 与 Diffusers 精读）合到一起梳理清楚。调研扩散模型和强化学习的交叉方向时，最容易混在一起的是两个完全相反的问题方向——先把两条路线分清，再重点拆解 Diffuser（Janner et al., ICML 2022）如何把“采样”和“规划”合二为一。

一、两条相反的主线：Diffusion for RL vs. RL for Diffusion

同样是把扩散模型和强化学习放进同一个系统，目标和对象可以完全相反：

方向 解决什么问题 核心建模方式 代表工作
Diffusion for RL 用扩散模型提升决策、规划与控制任务的策略表达力 把整条状态–动作轨迹或连续动作分布建模为扩散生成问题，结合奖励引导或 Q 函数对齐来选动作 Diffuser, Diffusion Policy, QSM, GenPO
RL for Diffusion 用 RL 微调图像/视频等生成模型，对齐难以求导的外部目标 把多步去噪链本身视为一个有限步 MDP（每步去噪即一次动作），用策略梯度直接优化下游奖励（美学、对齐度、压缩率等） DDPO, DPOK, Flow-GRPO

下面重点看第一条线——用扩散模型做轨迹规划与强化学习策略。

二、为什么把扩散模型引入 RL？

传统 RL 生成序列通常是自回归（autoregressive）的：观察当前状态 st，预测单步最优动作 at，转移到下一状态，如此循环。换成整条轨迹联合生成（Trajectory Optimization）后，模型不再一帧一帧贪心决策，而是一次性把整段时间跨度上的状态–动作序列联合看作一张“二维图”去优化累计回报。

这种结合带来了四个很直接的优势：

  • 多模态（多峰）轨迹表达：真实控制任务里往往存在多条同样合理的路径（比如绕过障碍物的左侧或右侧）。传统单峰高斯策略容易把两条好路径平均成一条撞墙的“折中动作”，而扩散模型天然可以表达复杂多峰分布。
  • 时序平滑与长程连贯：连续去噪过程会同时调整相邻时间步，生成的动作序列天然更平滑，不会像逐帧策略那样高频抖动。
  • 条件与约束注入灵活：初始状态、终点目标、避障约束或外部奖励信号，既可以作为条件输入网络，也可以在采样阶段通过引导梯度动态注入。
  • 离线分布先验 + 在线信号适配：先在离线轨迹数据上拟合动力学与行为分布，再用奖励引导或小步在线更新做任务适配，兼顾多样性与样本效率。

三、精读 Diffuser：让「采样」与「规划」合二为一

1. 背景痛点：Model-Based RL 为什么容易“钻模型空子”？

Model-Free RL 不显式学环境转移，直接学策略或价值函数（如 Q-learning、Policy Gradient），样本效率偏低；Model-Based RL 先用监督学习拟合一个环境模型（transition model + reward model），再在模型里做规划或模拟推演，样本效率高得多。

但现实里，学出来的环境模型和真实世界必然存在误差。如果直接拿强优化器在学出来的模型上搜索高回报轨迹，优化器会不自觉地专挑环境模型最不准的区域去“钻空子”（model exploitation）——规划器以为拿到了超高回报，一放到真实环境里执行就崩掉。这也是为什么很多现代 Model-Based 方法反而要大量借用 Model-Free 的价值函数与策略梯度来压制这种对抗性误差。

2. Diffuser 的核心想法：Sampling = Planning

Diffuser（Planning with Diffusion for Flexible Behavior Synthesis, ICML 2022）换了个思路：与其先学一个泛化的环境动力学模型再外挂规划器，不如直接训练一个轨迹级扩散概率模型，让“生成合法轨迹”和“规划高回报轨迹”变成同一个过程。

它的设计里最巧妙的三点：

  1. 二维轨迹矩阵 + 局部 1D 卷积 U-Net：把一段长度为 T 的轨迹拼成二维张量 τ = [s0, a0; s1, a1; …; sT, aT]。网络只用时序一维卷积，单步去噪只关注局部相邻时间步的动力学一致性，但多步迭代叠加之后，感受野自然覆盖整条轨迹，同时天然支持任意规划长度。
  2. 动力学与奖励解耦（Reward-Agnostic Pretraining）：扩散主干只学习离线数据中的可行轨迹分布 pθ(τ)，不绑死特定奖励函数；到了测试阶段，只要训练一个独立的回报估计器 Jφ(τ)，在每一步去噪均值上叠加梯度偏移，就能把采样推向高回报或满足多目标约束的区域：
p̃(τi−1 | τi) ≈ 𝒩(μθ(τi) + α Σ g, Σ),    g = ∇τ Jφ(τ)|τ = μ
  1. 起终点约束变成“图像补全（Inpainting）”：把当前观测状态固定在轨迹首端、目标状态固定在轨迹末端，在每一步去噪后强制覆盖两端取值，中间的动作与状态路径就会像图像修复一样自动补齐。

一个容易混的概念（Denoising vs. Sampling）：在扩散模型里，去噪（Denoising）指的是给定第 i 步带噪样本，用网络预测噪声或更干净一步 τi−1 的单步操作；采样（Sampling）则是从纯噪声 τK 出发，重复执行去噪直到 i = 0 得到最终轨迹的完整过程。
