GPT-2 论文精读：理论假设、工程细节与零样本实验全析

Chuyang Wei · Radford et al., OpenAI (2019), Language Models are Unsupervised Multitask Learners

在 BERT（2018）和 GPT-1（2018）刚刚把“无监督预训练 + 单任务微调”确立为 NLP 黄金范式的几个月后，OpenAI 在 2019 年初发表了 GPT-2。这篇论文之所以是整个现代大模型路线的转折点，不是因为提出了全新网络结构，而是用一整套严谨的零样本实验和泄漏排查证明了一件事：当数据多样性与模型容量跨过某个阈值，单纯优化下一个词似然，就能让语言模型在不做任何梯度更新的情况下涌现出多任务能力。

一、理论动机：从 $p(\text{output} \mid \text{input})$ 到 $p(\text{output} \mid \text{input}, \text{task})$

标准语言建模将一段符号序列 $(s_1, s_2, \dots, s_n)$ 的联合概率分解为条件概率连乘：

$$p(x) = \prod_{i=1}^{n} p(s_i \mid s_1, \dots, s_{i-1})$$

传统的单任务监督学习只学习 $p(\text{output} \mid \text{input})$，需要为每个任务单独设计输出头与标注集，结果往往在域外分布上极度脆弱（narrow experts）。而多任务系统应当建模的是以任务为条件的分布：

$$p(\text{output} \mid \text{input}, \text{task})$$

在 MQAN（McCann et al., 2018）等早期工作里，人们已经尝试把问答、翻译、摘要统一写成自然语言输入序列，但仍依赖大量人工有监督多任务语料。GPT-2 提出了一个更激进的理论观察：

无监督多任务学习的核心推论

由于自然语言本身能把“任务描述、输入与输出”全都装进同一串文本里（例如一段网页文本天然包含“translate to french, english text, french text”或“Q: ... A: ...”），那么任意有监督任务的目标，本质上只是大规模无监督语言建模目标的一个子集。因此，无监督语言模型的全局最优解，与所有包含在语料分布中的有监督任务的全局最优解是一致的——问题不再是“目标函数对不对”，而是模型容量和训练步数够不够逼近这个最优解。

二、数据构建与模型工程细节

2.1 WebText：用社区信号替代昂贵人工标注

为了获得既多样又干净的语料，作者没有直接拿噪音极大的 Common Crawl，而是抓取了 Reddit 上所有至少获得 3 个 karma（赞同票）的外部链接页面作为人工质量代理（heuristic quality filter）：

  • 原始外链约 4,500 万条，经 Dragnet 与 Newspaper 正文抽取及去重后，得到 800 万篇文档、约 40GB 文本；
  • 主动剔除全部 Wikipedia 页面，因为大量 NLP 评测集直接源自维基百科，剔除它能避免评测时数据重叠带来的虚高。

2.2 Byte-level BPE：零 OOV 与字符类别隔离

如果直接在 Unicode 码点上做 BPE，光基础字符集就超过 13 万，词表空间被严重挤占；而纯字节级语言模型在 1BW 等大基准上仍明显落后于词级模型。GPT-2 折中提出了字节级 BPE（Byte-level BPE）：

  • 基础词表固定为 256 个 UTF-8 字节，保证模型能给任意 Unicode 字符串分配合法概率，彻底消灭 <UNK>，也因此能跨任意分词/预处理规范评测任意数据集；
  • 关键工程修补：朴素字节 BPE 会因为标点高频共现把同一个词拆出 dog.、dog!、dog? 等多个重复槽位。作者强制禁止 BPE 跨字符类别合并（仅对空格保留例外以维持压缩率），最终定在 50,257 词表（256 基础字节 + 50,000 次合并 + 1 个 <|endoftext|>）。

2.3 架构微调与四档缩放配置

主干沿用 GPT-1 的 Decoder-only Transformer，但做了三处后来影响深远的稳定性改动：

  1. Pre-LN 结构：将 LayerNorm 移到每个子块（Self-Attention / FFN）的输入侧，并在最后一个自注意力块后额外加一层 LayerNorm；
  2. 残差路径初始化缩放：初始化时将残差层权重乘以 $1 / \sqrt{N}$（$N$ 为残差层总数，48 层模型即 $N=96$），避免残差流方差随深度线性发散；
  3. 扩展容量：上下文长度从 512 扩到 1024，batch size 增至 512。

三、实验设计与核心定量结果

所有下游评测均在严格 Zero-Shot（零微调、零任务梯度更新）条件下完成。评测语言建模时，作者使用可逆反分词器（invertible de-tokenizer）消除旧基准人为留下的空格/标点伪影（仅此一项就带来 2.5–5 PPL 收益），并按原基准单位严格换算概率。

3.2 常识推理、阅读理解、摘要与翻译

  • Winograd Schema Challenge（273 题常识消歧）：零样本达到 70.70%，较此前 SOTA 提升 7 个百分点，且随模型从 117M 扩到 1.5B 呈单调攀升。
  • CoQA 对话阅读理解：输入“文档 + 对话历史 + A:”贪心解码，零样本取得 55 F1，无需接触 12.7 万条人工标注 QA 对就打平或超过了 4 个有监督基线中的 3 个（但仍大幅落后于接近人类 89 F1 的有监督 BERT）。作者非常诚实地指出错误模式：模型经常走捷径，比如遇到 Who 问题就从文章里随便抽一个人名。
  • CNN/Daily Mail 文本摘要（原论文 Table 4）：在原文末尾拼 TL;DR: 诱导生成 3 句摘要（top-k=2 采样）：

  • WMT-14 机器翻译：尽管 WebText 刻意过滤了非英语网页、只剩约 10MB 法语文本，通过上下文示范 english = french，GPT-2 在 En→Fr 拿到 5.0 BLEU，在 Fr→En 拿到 11.5 BLEU（强英语生成先验明显利好译入英语，已超过部分早年无监督神经机器翻译基线）。
  • Natural Questions 闭卷问答（原论文 Table 5）：即便零样本总体 EM 只有 4.1%，但模型自身输出的概率校准度极高——在置信度最高的 1% 回答上准确率达到 63.1%，排名前 30 的高置信答案几乎全对（且经排查均未出现在 WebText 中）。

四、泛化 vs. 记忆：8-gram 数据泄漏排查（原论文 Table 6）

质疑零样本结果最常见的一句反问是：“是不是测试集早就混进 40GB 的 WebText 里被模型背下来了？”论文第 4 节专门用假阳性率上限 $10^{-8}$ 的 8-gram Bloom Filter 做了极严格的交叉重叠检测：

测试集 8-gram 重叠来源 PTB WT-2 enwik8 text8 WT-103 1BW 均值
与数据集自身训练集重叠 2.67% 0.66% 7.50% 2.34% 9.09% 13.19% 5.9%
与 WebText 训练集重叠 0.88% 1.63% 6.31% 3.94% 2.42% 3.75% 3.2%

结果颇为反直觉：主流 LM 测试集与 WebText 的平均重叠率仅 3.2%，甚至明显低于它们与各自官方训练集的平均重叠率（5.9%，其中 1BW 自身泄漏高达 13.19%）；Winograd 273 题里真正有实质上下文重叠的仅 1 题。此外，WebText 训练集与测试集上的 loss 曲线几乎贴合且仍在同步下降——说明 1.5B 模型此时处于明显欠拟合（Underfitting）状态，远未靠死记硬背刷分。

五、结论与历史定位

  1. 证明了无监督缩放的连续收益：从 117M 到 1.5B，几乎所有任务指标都随参数量呈平滑的对数线性改善，且完全没有触顶迹象——这直接催生了次年的 Scaling Laws（Kaplan et al., 2020）和 GPT-3（175B, Brown et al., 2020）。
  2. 确立了后代 LLM 的基础工程模板：Byte-level BPE、Pre-LN 残差结构、深度缩放初始化、启发式高质量网页过滤、以及基于 n-gram 去重/污染审计，此后多年一直是预训练的标准起手式。
  3. 诚实划清了 1.5B 的能力边界：论文并未夸大零样本结果——它在摘要、翻译与复杂阅读理解上明确弱于有监督专模，也解释了为什么后续必须靠更大规模（GPT-3 的 Few-shot In-Context Learning）以及指令微调 / RLHF 才能把潜藏能力稳定释放出来。
