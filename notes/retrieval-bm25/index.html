BM25 的概率由来：为什么词频必须饱和

2026-01-23 | 从概率排序原理、BIM、隐变量 Eliteness 到现代多阶段混合检索

哪怕进入长上下文和大模型 Agent 时代，只要面对远超单次窗口的语料库，检索（Retrieval）依然是不可替代的前置筛选层。而在工业级混合检索系统中，三十年前提出的 BM25 至今仍是与稠密向量检索并列的核心召回基线。

很多资料直接给出 BM25 公式，却不解释为什么 IDF 长成对数赔率、为什么词频项要带饱和分式 $\frac{(k_1+1)tf}{k_1+tf}$、以及长度归一化 $B$ 从何而来。这篇笔记从最底层的概率排序原理出发，一步步无跳步推完 PRP → 贝叶斯赔率 → BIM → IDF → 隐变量 Eliteness（词频饱和）→ BM25，再把它放回现代 LLM 多阶段检索管线里做定位。

1. 现代 LLM 检索漏斗里，BM25 为什么依然不可替代？

信息检索的技术演进大致经历了四代：从早期词法检索（Lexical Retrieval）追求字面精确匹配（不理解同义语义，但对专有名词、型号、代码符号的 Precision 极高），到深度学习时代的稠密语义检索（Dense Retrieval）靠双塔向量提升 Recall，再到工程上几乎标配的混合检索（Hybrid Retrieval：BM25 + Dense），最后演变为 LLM 时代的多阶段漏斗（Multi-stage Retrieval）。

下面回到信息检索的起点：给定包含 $N$ 篇文档的语料库 $\mathcal{D}$ 和由 $m$ 个词项构成的查询 $Q = (t_1, \dots, t_m)$，如何从第一性原理构造排序打分函数 $\text{score}(d, Q)$？

2. 从概率排序原理到 BIM：排序打分为什么是各词贡献之和？

2.1 概率排序原理与后验赔率

概率排序原理（Probability Ranking Principle, PRP）指出：如果我们能估计出每篇文档 $d$ 对查询 $Q$ 相关的后验概率 $P(R = 1 \mid d, Q)$，按该概率从高到低排序即可在决策论意义下最优。

先做最简抽象：对查询中的每个词项 $t_i$，定义二元指示变量 $x_i \in \{0, 1\}$（出现为 $1$，未出现为 $0$），于是文档 $d$ 在查询词上的表现就是二值向量 $\mathbf{x} = (x_1, \dots, x_m)$。相关性同样记为二元变量 $R \in \{0, 1\}$。直接比较 $P(R=1 \mid \mathbf{x})$ 带有归一化分母，转用单调等价的后验赔率（Odds）并用贝叶斯公式拆解：

$$\text{odds}(R=1 \mid \mathbf{x}) = \frac{P(R=1 \mid \mathbf{x})}{P(R=0 \mid \mathbf{x})} = \underbrace{\frac{P(R=1)}{P(R=0)}}_{\text{先验赔率（与文档无关）}} \cdot \underbrace{\frac{P(\mathbf{x} \mid R=1)}{P(\mathbf{x} \mid R=0)}}_{\text{似然比（证据强度）}}$$

2.2 条件独立假设与逐词加和结构

二元独立模型（Binary Independence Model, BIM）假设：在给定相关性 $R$ 的条件下，各查询词的出现相互独立，即 $P(\mathbf{x} \mid R) = \prod_{i=1}^{m} P(x_i \mid R)$。对后验赔率取对数（单调递增，不改变文档排序）并丢弃对所有文档相同的先验常数项，得到检索状态值（Retrieval Status Value, RSV）：

$$\text{RSV}(d, Q) \propto \sum_{i=1}^{m} \log \frac{P(x_i \mid R=1)}{P(x_i \mid R=0)}$$

这就是信息检索中「文档总分等于各个查询词贡献之和」的数学来源。

2.3 伯努利展开：精确推出词项证据强度 $c_i$

定义两个条件概率参数：

$$p_i = P(x_i = 1 \mid R = 1), \qquad r_i = P(x_i = 1 \mid R = 0)$$

分别表示词 $t_i$ 在相关文档与不相关文档中出现的概率。由于 $x_i \in \{0, 1\}$，可以用伯努利分布统一写作 $P(x_i \mid R=1) = p_i^{x_i}(1-p_i)^{1-x_i}$ 与 $P(x_i \mid R=0) = r_i^{x_i}(1-r_i)^{1-x_i}$。代入单个词项的对数似然比逐步化简：

$$\begin{aligned} \log \frac{P(x_i \mid R=1)}{P(x_i \mid R=0)} &= \log \frac{p_i^{x_i}(1-p_i)^{1-x_i}}{r_i^{x_i}(1-r_i)^{1-x_i}} \\ &= x_i \log\frac{p_i}{r_i} + (1 - x_i)\log\frac{1-p_i}{1-r_i} \\ &= \underbrace{\log\frac{1-p_i}{1-r_i}}_{\text{不含 } x_i \text{，排序时为常数}} + x_i \cdot \underbrace{\log\frac{p_i(1-r_i)}{(1-p_i)r_i}}_{c_i} \end{aligned}$$

忽略与文档无关的常数项，每当词 $t_i$ 在文档中出现（$x_i = 1$），它贡献的证据强度 $c_i$ 恰好拆成两部分：

$$c_i = \log\frac{p_i(1-r_i)}{(1-p_i)r_i} = \log\frac{p_i}{1-p_i} + \log\frac{1-r_i}{r_i}$$
  • $\log \frac{p_i}{1-p_i}$：词在相关文档里的出现优势（相关 odds）；
  • $\log \frac{1-r_i}{r_i}$：词在不相关文档里的稀有程度（反 odds）。

一个词如果既常出现在相关文档中（$p_i$ 大），又极少出现在不相关文档中（$r_i$ 小），它的证据强度 $c_i$ 就高。

3. 无标注场景下，词项证据强度如何退化为 IDF？

真实无监督检索里，系统并不知道当前查询对应的相关文档集合，因而无法估计 $p_i$。Robertson & Spärck-Jones 的经典做法是令先验无偏向：$p_i = 0.5$，此时 $\log\frac{p_i}{1-p_i} = \log 1 = 0$，证据强度退化为只依赖不相关文档中的稀有度：

$$c_i \approx \log\frac{1 - r_i}{r_i}$$

因为对任意查询，全语料库 $N$ 篇文档中绝大多数都是不相关的，包含词 $t_i$ 的文档数 $df_i$ 占比 $df_i / N$ 就是 $r_i = P(x_i=1 \mid R=0)$ 的近似最大似然估计 $\hat{r}_i \approx df_i / N$。代入上式立即得到经典的逆文档频率（IDF）原型：

$$c_i \approx \log\frac{1 - df_i/N}{df_i/N} = \log\frac{N - df_i}{df_i}$$

围绕这个原型，衍生出工程中最常见的三种 IDF 变体：

  • 经典 TF-IDF 近似：当查询词较稀有（$df_i \ll N$）时，$N - df_i \approx N$，化简为 $\log\frac{N}{df_i}$。
  • Robertson–Spärck Jones 平滑（RSJ IDF）：为避免 $df = 0$ 或 $df = N$ 造成除零与对数发散，分子分母各加 $0.5$： $$\text{IDF}_{\text{RSJ}}(t) = \log\frac{N - df(t) + 0.5}{df(t) + 0.5}$$
  • Lucene / 非负稳健变体：注意 RSJ IDF 在高频停用词满足 $df(t) > N/2$ 时会变成负数；工程实现（如 Lucene / Elasticsearch）常在真数内加 $1$，保证所有词项权重非负： $$\text{IDF}_{\text{Lucene}}(t) = \log\!\left(\frac{N - df(t) + 0.5}{df(t) + 0.5} + 1\right)$$

4. 引入隐变量 Eliteness：为什么词频必须饱和，以及 BM25 完整公式

BIM 的局限在于只看二值「出不出现」（$x_i = \mathbf{1}[tf > 0]$），无法区分一篇文档里「只提了 1 次」和「反复讨论了 10 次」。现在把观测变量升级为整数词频 $TF_t \in \{0, 1, 2, \dots\}$，类比 BIM，每个词的词频证据强度同样写成对数似然比：

$$w_t(tf) = \log\frac{P(TF_t = tf \mid R=1)}{P(TF_t = tf \mid R=0)}, \qquad \text{RSV}(d, Q) \propto \sum_{t \in Q} w_t(tf_{t, d})$$

4.1 为什么要引入隐变量 Eliteness（精英性）？

如果直接拟合 $P(TF_t = tf \mid R=1)$ 和 $P(TF_t = tf \mid R=0)$，每个词、每个查询的相关集分布都不一样，根本没有足够标注去估计参数。Robertson & Walker 的关键建模技巧是引入一个二值隐变量主题性 / 精英性（Eliteness, $E \in \{0, 1\}$）：

  • $E = 1$：该词是这篇文档的核心主题词（elite），因此往往高频出现；
  • $E = 0$：该词只是顺带提及或未提及（non-elite）。

把 $tf$ 看成由隐状态 $E$ 生成的观测结果，对 $E \in \{0, 1\}$ 做全概率展开：

$$P(TF = tf \mid R=1) = P(TF = tf \mid E=1, R=1) P(E=1 \mid R=1) + P(TF = tf \mid E=0, R=1) P(E=0 \mid R=1)$$

再引入条件独立简化：给定词是不是主题词 $E$ 后，词频分布的形状不再直接依赖查询相关性 $R$，记 $E_1(tf) := P(TF=tf \mid E=1)$，$E_0(tf) := P(TF=tf \mid E=0)$（在 2-Poisson 模型中它们对应两个不同速率参数的泊松分布）。相关性 $R$ 只通过改变「成为主题词的概率」起作用：令 $p_1 = P(E=1 \mid R=1)$，$p_0 = P(E=1 \mid R=0)$。于是得到两成分混合模型：

$$P(TF = tf \mid R=1) = p_1 E_1(tf) + (1 - p_1) E_0(tf)$$ $$P(TF = tf \mid R=0) = p_0 E_1(tf) + (1 - p_0) E_0(tf)$$

代回对数似然比定义，严格表达式为：

$$w(tf) = \log\frac{p_1 E_1(tf) + (1 - p_1) E_0(tf)}{p_0 E_1(tf) + (1 - p_0) E_0(tf)}$$

4.2 词频饱和（Saturation）的数学证明

当文档中词频 $tf$ 很大时，它几乎肯定来自主题词分布而非偶发分布，即 $E_1(tf) \gg E_0(tf)$。此时分子分母中的 $(1-p)E_0(tf)$ 项均可忽略，$E_1(tf)$ 被上下约掉：

$$\lim_{tf \to \infty} w(tf) = \lim_{tf \to \infty} \log\frac{p_1 E_1(tf)}{p_0 E_1(tf)} = \log\frac{p_1}{p_0}$$

这就是词频饱和的数学本质：当一个词已经出现足够多次时，系统基本确信 $E = 1$（该词就是主题词），此后每多出现一次带来的新信息增量趋近于 $0$，因此 $w(tf)$ 必须存在一个有限的水平渐近线，而不能像朴素 TF 那样线性无限增长。

4.3 BM25 的工程近似与文档长度归一化

直接估计 2-Poisson 混合模型的四个参数（$p_1, p_0, \lambda_1, \lambda_0$）在无标注检索中难以落地。BM25 用一个极简洁的解析函数复刻了 $w(tf)$ 的全部定性性质（$tf=0$ 时为 $0$、单调递增、$tf \to \infty$ 时趋于有限上限）：

$$\text{sat}(tf) = \frac{(k_1 + 1)\, tf}{k_1 + tf}$$

再把「上限高度」交给前文从 BIM 推出的 $\text{IDF}(t)$，就得到有效证据强度 $c^{\text{eff}}(t, d) = \text{IDF}(t) \cdot \frac{(k_1 + 1)\,tf}{k_1 + tf}$。

最后处理文档长度偏置：长文档之所以词频更高，可能仅仅是因为篇幅更长（Scope / Verbosity 假说），而不代表更相关。记当前文档长度为 $dl$，语料库平均文档长度为 $\text{avgdl}$，定义部分长度归一化因子：

$$B = (1 - b) + b \cdot \frac{dl}{\text{avgdl}}, \qquad b \in [0, 1]$$

用归一化后的有效词频 $tf' = tf / B$ 替换饱和函数中的 $tf$，上下同乘 $B$ 整理即得 Okapi BM25 的完整公式：

$$\text{BM25}(d, Q) = \sum_{t \in Q} \text{IDF}(t) \cdot \frac{(k_1 + 1)\, tf(t, d)}{k_1\!\left((1 - b) + b \cdot \dfrac{dl}{\text{avgdl}}\right) + tf(t, d)}$$

超参数 $k_1$ 与 $b$ 的物理直觉与边界行为

  • $k_1$（词频饱和速率，工程常用 $1.2 \sim 2.0$）：控制词频从 $1$ 增加到多次时得分上升的幅度。当 $k_1 = 0$ 时，饱和项恒为 $1$，BM25 精确退化回只看「出现与否」的 BIM 模型；当 $k_1 \to \infty$ 时，饱和消失，退化为线性 TF 加权。
  • $b$（文档长度惩罚强度，工程常用 $0.75$）：$b = 0$ 时完全关闭长度归一化（$B=1$）；$b = 1$ 时执行完全按比例的长度归一化（$B = dl/\text{avgdl}$）。在文档长度方差极大的混合语料（如网页 + 短标题 + 长 PDF）中，适度调低 $b$（如 $0.4 \sim 0.6$）常比默认 $0.75$ 更稳。

5. 放回现代 RAG 与 Agent 系统：词法、稠密与交叉重排如何配合？

理解了 BM25 的数学根基后，就能一眼看清它与神经检索各自的能力边界，以及为什么工业界几乎都采用 Hybrid（BM25 + Dense）+ Cross-Encoder Rerank 的组合：

检索层级 核心机制 典型优势 核心短板
BM25（词法召回） 倒排索引 + 精确词项 IDF/饱和 TF 统计 零训练、跨领域极稳；对实体名、报错码、函数名、缩写精确命中 存在词汇鸿沟（Vocabulary Mismatch），无法匹配同义改写或跨语言语义
Dense Bi-Encoder（稠密召回） Query 与 Doc 独立编码为向量，ANN 近似最近邻检索 捕捉语义相似与改写，长尾语义 Recall 强 压缩成单向量后丢失细粒度词法细节；领域迁移（如代码/专有缩写）容易漏召
Hybrid + RRF（混合融合） BM25 与 Dense 并行召回，用倒数排名融合 $\sum \frac{1}{k + \text{rank}_i}$ 无需对齐两种模型的分数量纲，稳定兼具精确符号与语义泛化 仍属于粗排阶段，Query 与 Doc 之间缺乏 token 级细粒度交互
Cross-Encoder / LLM Rerank 把 Query 与候选 Doc 拼接后联合做全注意力打分 捕捉精确逻辑约束、否定词与多条件匹配，Top-10 Precision 最高 无法离线预编码文档，计算量 $O(|C|)$，只能放在漏斗后端精排

总结：BM25 并非经验拼凑的公式，而是概率排序原理、伯努利似然比与主题隐变量饱和近似在无监督检索中的闭式落点。即使在 Agentic Search 和深度研究系统里，当模型需要检索代码标识符、特定数字指标或罕见专有名词时，BM25 提供的精确词法锚点依然是稠密向量难以替代的底层保障。
