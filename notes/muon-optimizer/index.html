Muon 为什么前期快、后期震荡

2026-06-25 | 基于个人学习笔记、Keller Jordan Muon 报告与近期谱优化理论整理

在 NanoGPT Speedrun 和多款开源大模型预训练中，Muon（MomentUm Orthogonalized by Newton-Schulz）用比 AdamW 少 30% 至 50% 的 token 就达到了相同验证集损失。但工程实践与近期理论分析也指出了它的局限：Muon 前期下降很快，到了训练后期却容易减速，甚至在最优点附近震荡。

这篇笔记把这两个现象放进同一套矩阵谱分析里讲清楚：先看传统优化器为什么会被少数大奇异值垄断，再拆解 Muon 如何通过矩阵正交化和五阶 Newton-Schulz 迭代实现谱拉平，最后结合近期联想记忆与河谷（River-Valley）动力学理论，说清它的加速来源、后期震荡原因与工程用法。

1. 为什么 SGD 和 AdamW 容易被少数大奇异值垄断？

对 Transformer 中间层的二维权重矩阵 $W \in \mathbb{R}^{m \times n}$（如注意力投影 $W_Q, W_K, W_V, W_O$ 和 MLP 权重），标准 SGD-Momentum 的更新规则是：

$$M_t = \beta M_{t-1} + (1 - \beta) G_t, \qquad W_{t+1} = W_t - \eta M_t$$

其中 $G_t = \nabla_W \mathcal{L}$ 是当前梯度。把梯度或动量矩阵做奇异值分解（SVD）：

$$M_t = U \Sigma V^\top = \sigma_1 u_1 v_1^\top + \sigma_2 u_2 v_2^\top + \dots + \sigma_r u_r v_r^\top$$

每一个秩一矩阵 $u_i v_i^\top$ 代表一个独立的矩阵更新方向，奇异值 $\sigma_i$ 决定这个方向的步幅。实际训练 Transformer 时，二维参数的梯度和动量矩阵往往严重病态（条件数极高，近似低秩）：前几个主导奇异值远大于其余方向（$\sigma_1 \gg \sigma_2, \sigma_3, \dots$）。结果每一步更新 $-\eta M_t$ 几乎全消耗在 $-\eta \sigma_1 u_1 v_1^\top$ 等高频主导方向上，大量承载长尾知识或稀有模式的较小奇异值方向长期得不到充分更新。

AdamW 虽然通过二阶动量做了逐元素（element-wise）缩放，但它把矩阵拍扁成独立标量看待，看不到行列之间的耦合结构，因此无法从矩阵谱层面消除各向异性。

2. Muon 的核心操作：把动量矩阵做正交化（Matrix Sign）

Muon 在 SGD-Momentum 的基础上只多了一步后处理：更新权重前，先把二维动量矩阵 $M_t$ 做正交化（求极因子 / Matrix Sign），即保留左右奇异向量 $U, V$，把奇异值矩阵 $\Sigma$ 全部拉平为 $1$：

$$\operatorname{Ortho}(M_t) = \operatorname{msign}(M_t) = U V^\top, \qquad W_{t+1} = W_t - \eta\, U V^\top$$

可以把这一步精确类比为标量符号函数向矩阵空间的推广：

  • 标量 $\operatorname{sign}(g)$：把 $g = 100$ 和 $g = 0.001$ 都压到 $+1$，丢掉幅度，只保留正负方向。
  • 矩阵 $\operatorname{msign}(M_t)$：执行映射 $U \Sigma V^\top \mapsto U V^\top$，做谱拉平（Spectral Flattening），让所有有效奇异方向以同等尺度推进，不再被最大奇异值垄断。

概念辨析：正交化不是「变成单位矩阵」

一组向量正交归一，意思是两两垂直（$a^\top b = 0$）且模长为 1（$\|a\| = \|b\| = 1$）。如果矩阵的列向量正交归一，满足 $Q^\top Q = I$；如果行向量正交归一，满足 $Q Q^\top = I$。对于非方阵 $M_t \in \mathbb{R}^{m \times n}$，正交化结果 $UV^\top$ 并不是单位矩阵 $I$，而是保留原始方向耦合结构、同时让各独立方向互不干扰且尺度统一的半正交矩阵。也正因依赖矩阵奇异谱，Muon 只适用于二维隐藏层矩阵；一维参数（Bias、LayerNorm）以及输入 Embedding / 输出 LM Head 仍需交回 AdamW 优化。

3. 工程上如何绕开 SVD：五阶 Newton-Schulz 迭代

如果在每个优化步都对大型权重矩阵做精确 SVD，计算开销会抵消加速收益。Keller Jordan 的关键工程突破，是用 5 步五阶奇数次 Newton-Schulz 多项式迭代在 bfloat16 下近似矩阵正交化：

$$X_{k+1} = a X_k + b (X_k X_k^\top) X_k + c (X_k X_k^\top)^2 X_k, \qquad X_0 = \frac{M_t}{\|M_t\|_F + \epsilon}$$

标量视角下，该迭代把区间 $[0, 1]$ 内的奇异值通过多项式 $\phi(x) = a x + b x^3 + c x^5$ 快速推向 $1$ 附近。Muon 选用的调优系数为 $a = 3.4445,\; b = -4.7750,\; c = 2.0315$，刻意最大化原点附近的斜率，使极小的奇异值在短短 5 步内也能迅速抬升（允许最终收敛到 $1$ 附近的一个小区间，实践证明这不影响训练效果，还能在低精度 bfloat16 下保持数值稳定）。 

def zeropower_via_newtonschulz5(G, steps=5):
    a, b, c = (3.4445, -4.7750, 2.0315)
    X = G.bfloat16()
    if G.size(-2) > G.size(-1):
        X = X.mT
    X = X / (X.norm(dim=(-2, -1), keepdim=True) + 1e-7)
    for _ in range(steps):
        A = X @ X.mT
        B = b * A + c * (A @ A)
        X = a * X + B @ X
    if G.size(-2) > G.size(-1):
        X = X.mT
    return X

对于 $m \times n$（设 $m \le n$）矩阵，每步迭代只需纯矩阵乘法（GEMM），复杂度 $O(m^2 n)$，高度契合 GPU Tensor Core。尽管单步优化器开销高于逐元素操作的 AdamW，但由于收敛所需总步数与 token 数大幅减少，总体 wall-clock 时间和累计训练算力仍显著优于纯 AdamW（NanoGPT 124M / 1.5B 等基准上综合效率接近翻倍）。

4. 理论解释：前期为什么快，后期为什么减速并震荡？

2026 年的两篇理论工作分别从「加速来源」和「收敛局限」两面给出了精确刻画：

4.1 前期加速：在重尾数据上放大弱信号（arXiv:2603.26554）

Kim 等人在 Sharp Capacity Scaling of Spectral Optimizers in Learning Associative Memory 中用线性联想记忆（模拟 Transformer 事实召回）分析了幂律重尾分布下的优化过程：

  • 在幂律频次分布下，SGD 的更新被高频条目主导，长尾条目恢复极慢。
  • Muon 仅用一阶梯度信息，单步存储容量就显著超过 SGD，甚至追平需要二阶 Hessian 的牛顿法，且临界 Batch Size 更大。
  • 多步动力学显示，Muon 的核心优势集中在初期恢复速率显著更快；但接近信息论极限时，收敛速度与 SGD 趋于同阶。

4.2 后期减速与震荡：河谷视角下的过度正则化（arXiv:2606.21514）

Towards Understanding the Power and Limits of the Muon Optimizer: A River-Valley Perspective 将高维矩阵优化问题借助不变流形（Invariant Manifold）约化为三维坐标（对应 signal / spike / bulk 三类谱分量），揭示了 Muon 在损失地形（河谷与山坡）上的两面性：

  • 训练前期，不同方向的梯度幅度悬殊，抹平奇异值正好消除了各向异性，让小奇异值方向不再被淹没。
  • 训练后期，参数已经逼近最优点（河谷底部），此时需要随残差自然缩小的步长。Muon 每一步仍把更新矩阵的奇异值归一化到 1（等价于过度正则化），在固定学习率下必然反复跨过谷底产生震荡（oscillatory）和有效推进减速（decelerating）。

5. 工程结论：混合配置与两阶段收敛策略

维度 SGD-Momentum AdamW Muon（2D 隐藏层）
更新结构 原始动量 $M_t$ 逐元素二阶矩归一化 矩阵极因子 $UV^\top$（五阶 Newton-Schulz）
适用参数 全部参数 全部参数（含 1D、Embedding、Head） 仅二维隐藏层矩阵，其余配 AdamW
核心强项 理论干净、显存开销最小 自适应尺度稳健，后期收敛平滑 重尾/异质数据前期推进极快，省 30%–50% token
主要风险 Transformer 高条件数下收敛极慢 无法从矩阵谱层面消除行列耦合各向异性 缺乏尺度衰减时易在谷底震荡，对 LR Decay 敏感

三条落地建议

  1. 参数分层搭配：隐藏层二维权重矩阵（Attention / FFN）用 Muon，Embedding、LM Head、Bias 与归一化层保持 AdamW。
  2. 匹配学习率衰减或两阶段切换：不要用恒定学习率把 Muon 跑到底；要么配合针对 Muon 标定过的学习率衰减（decay schedule），要么采用「前期 Muon 快速下山，后期切换 GD / AdamW 精细收尾」的两阶段调度。
  3. 先确认问题形态：在数据分布重尾、层内条件数高的大规模预训练中，Muon 的收益最明显；如果本身处于小学习率微调或接近收敛的局部精修阶段，普通 AdamW 往往更稳。
