01 / RESEARCH

A changing world.
A longer learning loop.

From experience to
lasting improvement.

A forecast can take weeks or months to resolve. What can an agent learn along the way, and what should persist when the next task begins?

01

Open-world forecasting

Building agents that gather evidence, track changing factors, and make calibrated predictions. I’m interested in reliable data access and evaluation that respects what was knowable at prediction time.

02

Learning from delayed feedback

Studying temporal signals before outcomes resolve, trajectory attribution, and credit assignment. The goal is to learn useful revisions from feedback that arrives across time.

03

Harness–model co-evolution

Exploring how context, tools, memory, and skills can improve with experience, and how training can internalize those capabilities into model weights.

FORECASTING AGENT / TEAM PROJECT

Milkyway

I contributed to building Milkyway, a forecasting agent system that previously reached first place on the public FutureX leaderboard.

My work spans forecasting-oriented harness design, context management, tool use, progressively disclosed skills, and multi-factor analysis.

An ongoing research direction: learning from temporal evidence before final outcomes are known.
